# PUBLIC REPO BOUNDARY

`goodly-geland` может быть публичным репозиторием, потому что GitHub Pages на бесплатном тарифе работает для публичных репозиториев.

Из-за этого здесь действует жёсткое правило:

```text
goodly-geland = только публичный SEO-сайт Obzornik / Geland / Goodly
```

## Что разрешено хранить здесь

- Публичные страницы сайта.
- Публичные SEO-статьи.
- Публичные обзоры продуктов.
- Публичные шаблоны страниц.
- Публичные настройки Astro/GitHub Pages.
- Публичные CTA-ссылки на магазин Geland.
- Публичные данные карточек продуктов, которые можно показывать покупателю.

## Что запрещено хранить здесь

- Внутреннюю память AI-агентов.
- Приватные заметки.
- Секреты, токены, ключи, `.env`.
- Данные других проектов.
- Материалы концертного проекта.
- Материалы mama-server.
- Материалы маркетинга жены, если они не предназначены для публичного сайта.
- КИС, YCLIENTS и другие направления, если для них не принято отдельное решение о публичной публикации именно на Obzornik.
- Непубличные коммерческие условия.
- Черновики, которые нельзя показать в открытом репозитории.

## Правило для новых тем

Перед тем как добавить новую тему в `goodly-geland`, нужно ответить на вопрос:

```text
Эта тема должна быть публичным SEO-разделом сайта Obzornik?
```

Если ответ не подтверждён — тему сюда не добавлять.

## Текущий разрешённый контур

На данный момент рабочий контур этого репозитория:

```text
Obzornik / Geland / Goodly
```

Задача: публичные SEO-страницы и обзоры обучающих продуктов с CTA на магазин Geland.

## Главный запрет

Никто и никакие чужие проекты не попадают в `goodly-geland` автоматически.

Каждая новая тема требует отдельного решения о публичности, структуре, CTA и границах.
