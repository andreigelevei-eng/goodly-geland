# TOPIC TEMPLATE

Копировать этот шаблон при создании новой темы.

## Файл темы

Путь:

```text
src/content/topics/<topic-slug>/_topic.md
```

Шаблон:

```markdown
---
topic: "Название темы"
slug: "topic-slug"
status: "active"
audience: "Для кого пишем"
commercial_goal: "Что должна делать тема: продажи, лиды, переходы, прогрев"
main_cta_text: "Текст кнопки"
main_cta_url: "https://example.com"
public_positioning: "Как тема выглядит для читателя"
internal_notes: "Внутренние заметки, не публиковать"
forbidden_claims:
  - "Что нельзя утверждать"
allowed_claims:
  - "Что можно утверждать"
---

```

## Файл карты статей

Путь:

```text
src/content/topics/<topic-slug>/_article-map.md
```

Шаблон:

```markdown
# Article Map: Название темы

## Цель кластера

...

## Главный CTA

...

## Кластер 1. Базовые запросы

- [ ] Статья 1 — `/topics/<topic-slug>/.../`
- [ ] Статья 2 — `/topics/<topic-slug>/.../`

## Кластер 2. Сравнения

- [ ] Статья 3 — `/topics/<topic-slug>/.../`
- [ ] Статья 4 — `/topics/<topic-slug>/.../`

## Кластер 3. Продуктовые обзоры

- [ ] Обзор продукта — `/topics/<topic-slug>/.../`

## Внутренняя перелинковка

- Главная тема → все кластеры
- Статьи → продуктовые обзоры
- Продуктовые обзоры → CTA

## Статус

- [ ] Карта утверждена
- [ ] Первые 5 статей готовы
- [ ] CTA проверен
- [ ] Страницы добавлены в sitemap
```
