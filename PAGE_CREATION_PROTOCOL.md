# PAGE CREATION PROTOCOL

Протокол создания страниц в `goodly-geland`.

## Цель

Чтобы любая новая тема превращалась не в хаос страниц, а в управляемый SEO-кластер с памятью, картой статей и понятными правилами публикации.

## Когда Андрей кидает тему

Например:

```text
Goodly — нужно 57 статей
YCLIENTS — сделать SEO-кластер
КИС — подготовить структуру
Маркетинг жены — отдельное направление
Нумерология мамы — отдельное направление
```

Агент НЕ начинает сразу писать статьи.

Сначала агент создаёт тему.

## Шаг 1. Создать slug темы

Примеры:

```text
Goodly → goodly
YCLIENTS → yclients
КИС → kis
Маркетинг жены → wife-marketing
Нумерология мамы → numerology
```

## Шаг 2. Создать папку памяти темы

```text
src/content/topics/<topic-slug>/
```

## Шаг 3. Создать `_topic.md`

Файл `_topic.md` — это память темы.

Он должен содержать:

```yaml
---
topic: "Goodly"
slug: "goodly"
status: "active"
audience: "..."
commercial_goal: "..."
main_cta_text: "..."
main_cta_url: "..."
public_positioning: "..."
internal_notes: "..."
forbidden_claims:
  - "..."
allowed_claims:
  - "..."
---
```

Ниже текстом:

```text
1. Что это за тема
2. Для кого пишем
3. Что продаём или куда ведём
4. Какой тон использовать
5. Что нельзя говорить публично
6. Какие источники использованы
7. Какие страницы уже созданы
8. Что делать дальше
```

## Шаг 4. Создать `_article-map.md`

Это карта всех статей темы.

Формат:

```markdown
# Article Map: Goodly

## Кластер 1. Обзор платформы
- [ ] Что такое Goodly
- [ ] Goodly для инфопродуктов
- [ ] Goodly или GetCourse

## Кластер 2. Продажа инфопродуктов
- [ ] Как продавать PDF-продукты
- [ ] Как сделать витрину обучающих материалов

## Кластер 3. Продуктовые обзоры
- [ ] Голос и харизма в тексте
```

## Шаг 5. Создать страницу только после карты

Статья или продуктовый обзор создаётся только после того, как она есть в `_article-map.md`.

## Шаблон SEO-страницы

Каждая страница должна иметь:

```yaml
---
title: "..."
description: "..."
slug: "..."
topic: "goodly"
category: "..."
ctaText: "..."
ctaUrl: "..."
keywords:
  - "..."
publishDate: "YYYY-MM-DD"
robots: "index, follow"
---
```

## Обязательная структура текста

```text
H1
Короткое вступление
Кому подходит
Что внутри / что важно знать
Практическая польза
Ошибки или ограничения
FAQ
CTA
```

## SEO-проверка перед сохранением

Перед сохранением проверить:

- title есть;
- description есть;
- keywords есть;
- robots есть;
- canonical формируется шаблоном;
- twitter meta формируются шаблоном;
- JSON-LD есть в шаблоне страницы;
- FAQ есть, если страница информационная;
- CTA ведёт на правильный URL;
- страница лежит в правильной теме.

## Ветки памяти темы

Для больших тем допускается отдельная ветка:

```text
topic/goodly
topic/yclients
topic/kis
topic/wife-marketing
topic/numerology
```

Правило:

- `main` — опубликованная стабильная версия.
- `topic/<slug>` — подготовка большой темы, карты и пачки статей.
- Смешивать темы в одной ветке нельзя.

## Что писать в коммите

Формат:

```text
Add Goodly topic memory
Add Goodly article map
Add Goodly article: <slug>
Add Goodly product review: <slug>
```

## Главное правило

Одна тема = одна память + одна карта + свои статьи + свой CTA.
