# Agent description for Goodly Reviews

Site: https://goodly.obzornik.online
Repository: andreigelevei-eng/goodly-geland
Language: Russian

## Purpose

This is a standalone public review site for Goodly educational materials and PDF products.

## Operating rules

- Keep the site independent.
- Do not expose private project maps or cross-project relationships.
- Do not create or reference a public Obzornik hub.
- Do not invent product facts.
- Use verified product source text for factual claims.
- Use market and competitor research only for context, page structure and search intent.
- All outbound links to `geland.goodly.pro` must include UTM parameters.
- Product pages should include transparent facts, audience fit, use cases, rights/bonus notes, FAQ and safe CTA blocks.

## Preferred page process

1. Research topic and target audience.
2. Analyze references and competitors.
3. Map search query to user pain.
4. Match pain to verified product facts.
5. Write neutral review copy.
6. Add UTM CTA links.
7. Record service summary in repository under `ops/pages/`.
