# Site Structure для Obzornik / Geland

**Дата:** 2026-05-30

**Репозиторий:** `andreigelevei-eng/goodly-geland`

**Назначение документа:** логичная карта разделов, категорий и публикационных кластеров для SEO-страниц и обзоров продуктов магазина Geland на Goodly.

---

## 1. Главный принцип структуры

Obzornik / Geland не должен выглядеть как хаотичная витрина “всего подряд”.

Позиционирование:

> Обзоры обучающих материалов по AI, маркетингу, инфобизнесу, онлайн-доходу, контенту и личной эффективности.

Каждая страница должна иметь:

- одну основную категорию;
- один основной поисковый интент;
- один главный CTA;
- честное описание продукта;
- корректное указание автора продукта, если автор известен;
- ссылку на Goodly/Geland как место получения доступа.

## 5. Правила перелинковки

### AI → Infobusiness

Статьи про AI должны вести на продукты про создание курсов, гайдов и контентных систем.

Пример:

- `Промпт-мышление` → `Создай свой первый курс с ИИ`
- `Конвейер AI-контента` → `Смысловой контент`
- `Как не потерять работу из-за AI` → `Экспертность как продукт`

### Infobusiness → Marketing

Статьи про создание продуктов должны вести на продвижение.

Пример:

- `Система прибыльных гайдов` → `Прогрев без давления`
- `Формула спроса` → `Генерация лидов`
- `Экосистема инфопродуктов` → `Система повторных продаж`

### Content → Texts

Статьи про блог и контент должны вести на стиль и письмо.

Пример:

- `Как вести блог, если не хочешь быть блогером` → `Голос и харизма в тексте`
- `Смысловой контент` → `Пиши как профессионал`

### Self-development → Infobusiness / AI

Статьи про энергию, устойчивость и обучение могут вести в коммерческие кластеры.

Пример:

- `Личный ритм после 40` → `GPT для новичков 40+`

## 6. Что нужно для качественных публикаций

Есть 3 уровня исходников.

### Уровень A — лучший

Полный PDF/гайд продукта.

Подходит для:

- сильного SEO-обзора;
- подробной статьи;
- честного блока “что внутри”;
- FAQ;
- микроразметки;
- поддерживающих статей вокруг продукта.

### Уровень B — нормальный

Описание из служебного чата + название + формат + объём + основные выгоды.

Подходит для:

- карточки продукта;
- короткого обзора;
- первичной SEO-страницы;
- каталожного описания.

Ограничение: меньше уникальности и меньше глубины, чем при наличии PDF.

### Уровень C — минимальный

Только название и цена.

Подходит только для:

- каталога;
- временной заглушки;
- планирования структуры.

Для полноценной SEO-статьи недостаточно.

## 7. Канонический вывод

Для публикационной стратегии использовать такую связку:

```text
раздел → категория → обзор продукта → поддерживающие статьи → CTA на Goodly/Geland
```

Публикации не делать хаотично. Сначала строить кластеры, потом расширять их поддерживающими статьями.

Приоритет: AI → Infobusiness → Marketing → Content/Text → Self-development → Finance.
