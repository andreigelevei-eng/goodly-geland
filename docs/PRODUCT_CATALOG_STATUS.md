## Что важно для будущей работы

### Для полноценной SEO-страницы

Лучший источник — полный PDF/документ продукта.

Он нужен для:

- точного блока “что внутри”;
- подробного обзора;
- FAQ;
- поддерживающих SEO-статей;
- корректного описания результата;
- снижения риска общих формулировок.

### Для временной карточки

Достаточно:

- названия;
- цены;
- служебного описания из библиотеки;
- формата;
- объёма;
- главных выгод.

### Для каталожной заглушки

Достаточно:

- названия;
- цены;
- категории;
- slug.
